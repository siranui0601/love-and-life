# Stage 1 visual polish note

This branch continues the first no-hand soccer prototype by improving the pitch shell and canvas rendering without changing the underlying Matter.js physics tuning.

- CSS shell: richer stadium-like background, glass panels, premium field frame, stronger result overlay.
- Canvas pitch: grass stripes, slope shading, penalty boxes, goal frames, net lines, slope arrows.
- Ball: shaded soccer ball with pentagon/panel details.
- Players: top-down jersey silhouettes with heads, legs, shorts, shadows, labels, and keeper patrol guide lines.

Physics behavior is intentionally left unchanged from the initial Stage 1 prototype.
