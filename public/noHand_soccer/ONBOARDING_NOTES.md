# Onboarding UX follow-up

This PR focuses on making the first play understandable before adding more systems.

## Intent

- Show only the ball and the first yellow goal during the first tutorial moment.
- Hide field emojis and own-goal hazards until after the first successful goal.
- Explain that field emojis are materials collected by touching them with the ball.
- Make kickoff the only run button; outside kickoff is always the editable state.
- Teach generation, placement, movement, and rotation at the moment each action becomes relevant.
