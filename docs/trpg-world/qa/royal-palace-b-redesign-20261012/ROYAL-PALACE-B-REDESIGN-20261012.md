# 王城B案：宮殿重視・保全付き再構築設計（2026-10-12）

## 決定事項
ユーザー承認：B（宮殿重視）。外郭防御を保持しながら、王城の主役を城壁ではなく、主宮殿・王族居館・礼拝堂・官房・アーチ回廊・庭園・塔群へ移す。建物は用途、階数、構造、屋根、増改築の経緯を一棟ずつ設計する。人用階段と貨物導線を分離し、荷物は昇降機＋短い荷車道を使う。急勾配は許容するが複数経路を維持。

## 施工フェーズと受入条件
1. **現況保全監査**：既存施設の外形・入口・通路中心線・支持地盤・設備を3D座標とスクリーンショットで記録。保存済み正本は変更しない。
2. **低詳細の王宮再配置案**：既存宮殿と別コレクションに、建物ごとの輪郭・高さ・棟数・中庭を配置。城内ルートと入口に対する建築物の衝突を調べる。
3. **建築群の詳細造形**：建物ごとにファサード・屋根形状・塔・アーチ・バルコニー・控壁・窓の規則を作る。繰返し建物を無差別に複製しない。
4. **都市からの眺望**：正面、左右側面、下町、城壁下、歩行者視点で比較し、宮殿が主役として読めるか検証。
5. **通行・QA**：城門→謁見棟、宮殿→礼拝堂、使用人動線、貨物昇降機→厨房、城壁巡回の5系列を床・頭上・横幅・複数入口で検証。
6. **採用**：独立`.blend`と施工プランのQA通過後のみ、バックアップ付きで正本更新。現段階では既存の`current_royal_masonry`、施設や通路を消さない。

## 未確定／判断を要しない技術事項
- 個別建物の高さ、屋根、配置、アーチ、細部は上記方針に従って試作し、複数視点で評価して決める。
- 儀礼空間と物流が交差しない構造を原則とする。
- 宮殿は軍事要塞一辺倒に戻さない。装飾的で階層的な王宮都市景観を優先する。
