# 王都 Vertical Slice — 2026-10-01

## 位置づけ

`/capital-review/` は、王都を「建物を並べた背景」ではなく、実際に歩けるオープンワールド都市として成立させるための制作側レビューである。ゲーム本編のNPC AI・戦闘・セーブ・事件進行はまだ接続しない。

参照優先順位は次の通り。

1. TRPGスプレッドシート正本（2026-10-01時点で29シートを横断確認）
2. 都市/レベルデザインDeep Research PDF
3. 現行 `world-blueprint` / 広域地理契約
4. 王都イメージ画像（景観・密度・高低差の参考。正本ではない）

## 三つのスケール

- **atlas silhouette**: 世界地図から都市として読める大きな輪郭。高密度市街そのものではない。
- **authored core**: 6.49998 km² ≒ **6.5 km²**。今回高密度に設計・歩行検証する範囲。
- **activity envelope**: **約22 km²**。門外街道、河岸物流、郊外農地、行政/王城背面の利用圏を含む。城壁coreの相似拡大は禁止し、地形と人流に沿った非相似形で作る。

## レベルデザイン

Deep Researchで扱った **paths / edges / districts / nodes / landmarks** を、見た目の説明ではなく実データとして落とした。

### Cognitive map

- 王城 = 第一ランドマーク
- 宮廷魔術塔 = 第二の垂直ランドマーク
- 中央市場 = major node
- 城壁・河川 = edge
- 9地区 = district
- 大通り・生活路・裏路地・階段/低屋根 = path

さらに建物生成時に、以下の視線回廊を本当に空ける。

- 西門内 → 王城高塔
- 南大橋 → 王城
- 亜人街 → 宮廷魔術塔

「ランドマークがある設定」だけで終わらせず、遮蔽物配置から視認可能性を確保する。

### Compression / release

圧縮点:
- 3主要城門
- 社会ゲート
- 橋詰

解放点:
- 中央市場
- 駅馬車転回庭
- 王城前庭
- 魔術塔観測庭
- 下層共同井戸など

狭い門/橋/坂から広場へ抜けるリズムを作る。

### Route choice

各公開城門 → 中央市場には最低2本の意味の異なる経路を持たせる。

現時点の平時実歩行レビュー値（1.4m/s + 上り補正）:

- 西門 → 市場: 約1.22 km / 約15分
- 南門 → 市場: 約1.38 km / 約16分
- 東門 → 市場: 約1.66 km / 約20分
- 市場 → 王城: 約1.16 km / 約15分、上り約55m

広域R06等のmacro時間とは別物である。

### 地区差

地区を単なる色違いにせず、以下を別々に設定する。

- 街路幅
- 建築密度
- 建物高さ
- 地面/舗装
- 生活者の職業
- 社会的アクセス
- 夜間/事件時の危険度
- 高低差

### Social gating

王城・貴族街・魔術塔は敵レベルで塞がない。身分/許可等を将来接続できる topology とする。数値閾値は正本に存在しないため、このvertical sliceでは捏造しない。

### 同じ街の状態変化

T10 / T11 / T16 / T17は専用別マップにしない。同じ道、橋、施設、広場が平時・調査・封鎖・避難で役割を変える。

- T10: 孤児院 ↔ 役所 ↔ 瓦版 / 同一敷地の状態変化
- T11: 王城・行政・証言経路
- T16: 亜人街から下層/市場/東側への複数避難
- T17: 魔術塔の社会/警備ゲートと調査迂回

## 水と天候

局所支流は通常 **12–20m**、代表値16m、増水時22mでレビューする。既存広域本流の値は上書きしない。

低橋は増水時に閉じるが、高橋を使う代替都市循環が残る。川は景観線ではなく経路選択・物流のedge。

## NPC circulation

11種の生活導線を同じ街路グラフで検証している。

商人、衛兵、役人、貴族、荷運び、職人、駅馬車、孤児院関係者、瓦版売り、亜人住民、宿泊客。

NPC専用のワープ導線を作らず、プレイヤーと同じ物理道路を使う。

- 連続地形と北側高台
- 1,000棟超の街区mass
- 城壁/3門
- 道路階層
- 河川/4橋
- 王城と宮廷魔術塔の垂直ランドマーク
- 市場の解放空間
- 事件/増水の仮設通行制限
- WASD/タッチ歩行と衝突

最終アートではなく、歩行時間・見通し・密度・高低差・経路選択の検証用。
