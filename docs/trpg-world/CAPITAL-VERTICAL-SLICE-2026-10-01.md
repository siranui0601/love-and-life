## レベルデザイン

Deep Researchで扱った **paths / edges / districts / nodes / landmarks** を、見た目の説明ではなく実データとして落とした。

### Cognitive map

- 王城 = 第一ランドマーク
- 宮廷魔術塔 = 第二の垂直ランドマーク
- 中央市場 = major node
- 城壁・河川 = edge
- 9地区 = district
- 大通り・生活路・裏路地・階段/低屋根 = path

さらに建物生成時に、以下の視線回廊を本当に空ける。

- 西門内 → 王城高塔
- 南大橋 → 王城
- 亜人街 → 宮廷魔術塔

「ランドマークがある設定」だけで終わらせず、遮蔽物配置から視認可能性を確保する。

### Compression / release

圧縮点:
- 3主要城門
- 社会ゲート
- 橋詰

解放点:
- 中央市場
- 駅馬車転回庭
- 王城前庭
- 魔術塔観測庭
- 下層共同井戸など

狭い門/橋/坂から広場へ抜けるリズムを作る。

### Route choice

各公開城門 → 中央市場には最低2本の意味の異なる経路を持たせる。

現時点の平時実歩行レビュー値（1.4m/s + 上り補正）:

- 西門 → 市場: 約1.22 km / 約15分
- 南門 → 市場: 約1.38 km / 約16分
- 東門 → 市場: 約1.66 km / 約20分
- 市場 → 王城: 約1.16 km / 約15分、上り約68m（pass 3で進行方向と途中の地形を含めて再計測）

広域R06等のmacro時間とは別物である。

### 地区差

地区を単なる色違いにせず、以下を別々に設定する。

- 街路幅
- 建築密度
- 建物高さ
- 地面/舗装
- 生活者の職業
- 社会的アクセス
- 夜間/事件時の危険度
- 高低差

### Social gating

王城・貴族街・魔術塔は敵レベルで塞がない。身分/許可等を将来接続できる topology とする。数値閾値は正本に存在しないため、このvertical sliceでは捏造しない。

### 同じ街の状態変化

T10 / T11 / T16 / T17は専用別マップにしない。同じ道、橋、施設、広場が平時・調査・封鎖・避難で役割を変える。

- T10: 孤児院 ↔ 役所 ↔ 瓦版 / 同一敷地の状態変化
- T11: 王城・行政・証言経路
- T16: 亜人街から下層/市場/東側への複数避難
- T17: 魔術塔の社会/警備ゲートと調査迂回

## 水と天候

局所支流は通常 **12–20m**、代表値16m、増水時22mでレビューする。既存広域本流の値は上書きしない。

低橋は増水時に閉じるが、高橋を使う代替都市循環が残る。川は景観線ではなく経路選択・物流のedge。

NPC専用のワープ導線を作らず、プレイヤーと同じ物理道路を使う。

## Level-design pass 2

Deep Researchの原則を「説明文」だけで残さず、制作レビューで選択・検査できる `levelDesignBeats` としてデータ化した。

- **compression**: 城門や検問を狭く感じさせ、次の空間の解放を強める。
- **release**: 駅馬車庭・中央市場など、人流が一度ほどけて選択をやり直せる場所。
- **prospect**: 南大橋から水面と王城高台を同時に見せ、都市の構造を一望できる。
- **refuge**: 下層の共同井戸のように、狭い生活路の中で一度立ち止まれる小さな安全感。
- **desire path**: 低屋根歩廊・裏路地など、正規大通り以外を読む価値のある近道。
- **social gate**: 王城の身分/許可によるchokepoint。戦闘力の壁にはしない。
- **decision**: 亜人街のように、平時の生活と事件時の避難の両方で複数方向へ分岐できるnode。
- **hazard edge**: 河岸のように、天候によって最短経路の価値が変わるedge。
- **reveal**: 王城・魔術塔を曲がり角や坂の先で再提示し、UIなしで方向回復させる。

また、道路edgeごとに `designRole` を持たせた。主要物流、儀礼/方向づけ、生活回遊、業務物流、裏路地、階段/低屋根ショートカット、広域接続を区別する。3主要門→中央市場の代替経路は単に1 edgeだけ違う枝ではなく、edge集合のJaccard類似度が0.75未満になることをテストする。

3Dレビューの通常移動速度も設計値と揃えて **1.4m/s** とし、Shiftのみ4.5m/sの走行に変更した。これによりUIに表示する徒歩時間と実地形上の体感を分離しない。
