# 連続世界と集落規模の再設計

2026-09-29。読取基準: `f65a93a7a5dd9a78e235ee56bb7a9aa930a2261d`。実装済みという報告ではなく、現在値の測定と次のgraybox構築方針。コード・生成contentはこのレビューでは変更していない。

要塞・黒嶺は全棟10×9×3.8m。王城15×12×8mは王都市場18×9×5mと同程度の床面積で、城郭としての囲い・複合建築・儀礼前庭・防衛の深さを持たない。間口だけの拡大、庭の命名、低い壁、地面の色分けでは都市階層は成立しない。

## 参照と優先関係

- 直近ユーザー指定の一枚の世界・街道外も歩ける地理を優先する。親タスクから共有されたatlas配置: 西海岸に交易港、中央の合流河川に王都、南に農村、さらに南の乾燥台地に神殿/辺境、北西山地に洞窟、北の雪山に要塞、北東火山地帯に黒嶺、東に森/里、南西沖に犯罪都市。このレビュー担当は添付画像自体を直接見ていない。
- repositoryの `tools/trpg-world/sources/world.json` の拠点一覧、各地域、距離一覧を読んだ。王都は複数地区の巨大都市、要塞は補給と防衛、黒嶺は別国家の生活と政治という材料を確認。これは保存済みsourceで、今回live Sheetの再読を代替したと称さない。保存sourceには「総合設計書」tabがない。
- [The Level Design Book: Flow](https://book.leveldesignbook.com/process/layout/flow) は、速度・向き・見通し・移動機能を一緒に扱い、grayboxで実際に歩く検証を求める。本作では交通目的ごとの通りと、圧縮/開放する視界を採用する。
- [Wayfinding](https://book.leveldesignbook.com/process/blockout/wayfinding) は、プレイヤーが同じ空間を異なる目的で使うことを前提とする。本作では一本の正解筋でなく、地区・境界・交点・ランドマークから道を選べる構成にする。以下の寸法・密度は本作のauthoring提案であり、資料にある標準値ではない。

道路は通りやすい経路であり、道路graph外を通行不可にする柵ではない。野原・緩斜面・林床へ逸れられること。崖、水深、岩盤、塀、許可された技能など実条件で移動可否を決める。R05の地下坑道は地表と同じx,zでも別の高さ/接触層を持ち、地上人物を壁越しに知覚しない。

## atlas-reviewで先に検証すること

1. 一枚の地形上で村→王都→西海岸、王都→森、北の軍事/山岳→黒嶺が繋がる。道路外を歩け、streaming seamで位置が飛ばない。孤立したregion平面を空白で繋ぐだけにしない。
2. 同じ目線/FOV/人間scale、地域名を隠した状態で村・王都・要塞・黒嶺を見比べる。王都は連続街区と城郭、要塞は門/防衛/軍需、黒嶺は岩と水利の都市構造が識別できる。
3. 王都の城門から全施設は見えない。城の上部は方向を示し、市場は街区の曲がりを経て開ける。裏道が物理的に別の接触・視界を持つ。
4. 同じ土地区画を住民、仕事、荷車、警備が使える。美術用の道路と別の不可視NPC経路を作らない。
5. atlasの俯瞰・人間目線・自由歩行を別に記録する。authoring viewerで歩けても、既存authoritative gameplayの接続を確認するまでruntime完成とは呼ばない。
6. semantic施設/actor/事件ID、source参照、ownership、履歴は維持。旧local位置から新metric位置へのmigrationは明示変換し、知らない場所へNPCを都合よく送らない。

P1: 共通terrain/collision/heightのruntime接続、metric座標migration、各都市の実居住/施設量、交通の道中接触、地下層、普通のプレイヤー操作での連続移動。
P2: final art、素材、外壁装飾、照明の完成。これらを先に磨いてもP1は解消しない。
