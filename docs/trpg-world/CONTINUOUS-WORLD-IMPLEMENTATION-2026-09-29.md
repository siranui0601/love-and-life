# ひとつの3D世界 — 連続地形graybox（2026-09-29）

## 引継ぎ元と目的
Astra Ultraが使用上限で中断した時点の未コミットファイル src/shared/trpg-world/continuous-world.js と設計レビューを回収し、その配置データを維持しつつ「実際に3Dで描き、ひとつのワールド内をWASDで歩く」プレビューへ接続した。旧atlasを小修正して採用したわけではない。画像をメートル縮尺として扱わず、地形構成と相対的な集落階層を重視する。

## 今回動くところ
- 共通地形フレーム X=-1250..1250 / Z=-950..950、10m間隔の連続高さ場（47,941頂点）。
- 陸と海、西岸・離島、北の山と雪、北東の黒嶺、南の乾燥地、東の森林、河川、15のroute authoringをひとつのBabylon.jsシーン上に描画。
- 全11拠点を同じ地形上に埋め込む。王都154棟には城壁・宮殿・巨大主塔、黒嶺113棟、交易都市50棟と倉庫・埠頭。要塞の二重防壁、神殿回廊、ドワーフ工房、エルフの世界樹、農村の耕作帯を区別。追加された視覚棟はNPC/住民が増えたという意味ではない。
- 約1567本の樹木は薄いインスタンス描画。幹の通行障害はレンダラと共通の座標authoringで検査。
- 地上モードでWASD / Shiftで自由歩行。同じ地面を道路内外で進む。海や建物、木、斜面を衝突判定。地図の拠点セレクターは設計者の高速確認であり、ゲーム本編の瞬間移動ではない。
- R10は元の距離一覧に合わせて田園の村―古代神殿に修正。R08航路は海に表示、R05地下経路は地表の偽道路として描かない。
- 開発プレビュー: node tools/trpg-world/spatial-review-server.mjs を実行、/atlas-reviewを開く。
- 独立したbrowser entryで構成。単体バンドルを生成すれば公開webページとして配信可能。
