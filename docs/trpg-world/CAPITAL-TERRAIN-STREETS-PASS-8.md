## 今回の実装

- 連続した丘の標高場を入力とし、32mごとの平場と擁壁の地盤を生成。
- 道路交差点の高さを共有し、一般道18%以内の縦断を計算して切通しを形成。
- 元からある幹線同士も交差点で分割。高さの違う道路が平面だけで交差する事故を防ぐ。
- 上りの生活路を横へ回り込む折返しへ変更。10mの階段走行部ごとに2mの平場を共通歩行面へ追加。
- 道路と城壁の平面配置から半辺法で閉じた街区を抽出し、敷地が街区をまたがないよう制限。
- 視線回廊では建物だけでなく地盤の実際の切欠きも考慮。視認判定を強制成功にはしない。
- 2Dの建物は全頂点を世界座標から投影。画面上の矩形回転で代用しない。
- 2D「地盤・街路・街区」と3Dの建物非表示を追加。
- GitHub Actionsで実際のBabylon/Playwright歩行と画像取得を行うjobを追加。
