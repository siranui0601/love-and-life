# 人徳ルート 一本道 時刻表

Day1からトラブル全解決までを、実際に歩ける一本の時系列として書く。

これは仕様書ではなく**道そのもの**である。閾値や発火条件を並べてシミュレータが偶然通るのを
待つのではなく、何日の何時にどこで何を選び、その結果として空腹・疲労・所持金が
いくつになるかを先に書き切る。実装はこの道をなぞる。

## 書き方の約束

- **同じ場面は二度書かない。** 同じ場所へ戻る時は、必ず時間が経ち、誰かが動き、
  何かが失われた後の別の場面として書く。同じ三択が再び出ることはない。
- **生活は行の一部。** 空腹・疲労・所持金は列として毎行持つ。買えない物は買えない。
  食べられない日は食べられないまま次の行へ進み、その結果が後の行に出る。
- **倒れたら別の場所で目覚める。** 元の場面へは戻らない。誰が拾ったかで次の道が変わる。
- **事件だけを並べない。** 飯、寝床、寄り道、無駄話、戦闘、失敗を同じ密度で書く。
- **働く日には働き口を置く。** 所持金が増える行には、必ず対応する働き口がある
  （`labour-catalogue.md`）。稼げる場所が無いまま金が増える行を書かない。
- **同じ働き口は反復するが、繰り返さない。** 何を扱い、誰と組み、何が起き、何を聞いたか。
  この四つを毎回変える。そして**何も起きない回を必ず混ぜる。**
- **スキルで解けるようにしない。** スキルは戦闘専用である（下記）。
- 正本（TRPGスプレッドシート）の日付・NPC・施設・価格に従う。推測で作らない。

## スキルは戦闘の外に出ない

正本のスキルデータの形が、そう言っている。

```
target: "single_enemy"     damage: { perHitMultiplier, hits, accuracyModifier }
costs: { mp, hp }          cooldown: { battleTurns, usesPerBattle }
```

対象は敵、効果は倍率と命中、消費はMPとHP、冷却はターン数。
**戦闘の外へ出る欄が一つも無い。**だから道の側でこう決める。

- **どのスキル構成でも、T01からT19まで全部に到達できる。**
  「このスキルが無いとクリア不可」を一つも作らない
- **会話の成否をスキルで判定しない。**Day37でニコラスが妹の話をするのは、
  夕方の裏路地で二時間待った者にだけである。説得スキルの数値ではない
- **労働にスキルを要求しない。**荷役に筋力値は要らない。通った回数だけが条件である
- **戦闘は避けられる。**この道は四十八日間、武器を一本も買わずにDay48の奪還まで行く

**スキルで変わるのは、戦う時にどう戦うかだけ。**
戦うかどうか、勝った後に何が残るかは、スキルの外側で決まる。

## 訂正 ｜ 「全解決には届かない」は私の誤りだった

**一つ目。正本の期限列は三つある。**「発生/兆候」「主要期限」「最終悪化」。
