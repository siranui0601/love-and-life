# 無名ルート ｜ 名乗らないまま歩く

**三本目。**分岐は**Day41、宮廷魔術塔で名乗るかどうか**（`route-branches.md` の四番目）。

- **人徳ルートが取ったもの**：宮廷魔術塔で名乗る
- **この道が取るもの**：証拠をルカとライラに渡して自分は下がる
- **戻れなくなること**：**匿名のまま八十五日を終える。そしてT17は止まらない**

---

## この道の存在理由 ｜ 初めて失敗を含むルート

**人徳ルートも討伐ルートも、失敗0で終わっている。**

| | 解決 | 起こさせなかった | 失敗 |
|---|---:|---:|---:|
| 人徳ルート | 16 | 3 | **0** |
| 討伐ルート | 16 | 3 | **0** |
| **無名ルート（見込み）** | **15** | **3** | **1** |

**十九件に届かない道を一本書かないと、「届く」ことの意味が測れない。**
**これが三本目にこの道を置く理由である。**（当初は「旧稿が使えるから安い」と書いていた。**理由が変わった。**）

### T17を落とすと何が動くか

正本のT17失敗後の世界変化——

> **Day41儀式強行。**異界の魔物、空殻の勇者、王都地下の召喚亀裂などが発生。
> **Day63以降、王都の召喚災害が表面化。**

そして関連欄——**「T04を悪化させる。」**

**T04の側の関連欄にも書いてある。**

> **T17失敗で悪化・封鎖早期化。**

### ⚠ 硬い制約 ｜ T04はDay41より前に解く

**T04の最終悪化はDay50である。だがこの道では当てにできない。**
**T17がDay41に強行され、神殿の封鎖が早まるからである。**

| | 人徳ルート | 討伐ルート | **無名ルート** |
|---|---|---|---|
| T04を解いた日 | Day33〜34 | Day35〜37 | **Day41より前でなければならない** |
| 根拠 | 最終悪化Day50 | 最終悪化Day50 | **T17失敗で封鎖早期化** |

**二本とも偶然Day41より前に解いている。**だからこの制約に気づかずに済んでいた。
**この道では偶然に頼れない。**

### T11も重くなる

正本のT11の関連欄——**「T17王都上層部の暴走にも影響。」**

**主要期限Day49は、儀式強行のDay41の八日後である。**
**上層部が暴走している最中に、その上層部が守る王を守ることになる。**

### この骨格の三つの山

1. **Day32〜34の古代神殿。**Day41より前という制約が、日程全体を前に押している
2. **Day41。**分岐点であり、**この道で唯一「解けたのに解かない」日**である
3. **Day63以降。**T17の最終悪化と、T16（発生Day62）が重なる。
   **召喚災害が表面化した王都で、亜人排斥を鎮める**——**最も難しい二十日になる**

### 討伐ルートとの差（書く時に効く）

| | 討伐ルート | 無名ルート |
|---|---|---|
| T13を解く日 | Day17 | **Day21〜26**（森へ行く動機が違う） |
| 王都の扉 | **オルヴェンの紹介状** | **使えない。**下層と阻止派 |
| T11の味方 | セラフィム（Day40に通じた） | **いない。**Day41に下がったため |
| Day63〜80 | T14→T16、平常の王都 | **召喚災害の王都** |
| 最終形 | 解決16・失敗0 | **解決15・失敗1** |

**「軽い道」ではない。**匿名を選ぶと、**扉が減り、味方が減り、後半の王都が荒れる。**
**十九件のうち一件を捨てて買うのは、自由ではなく難度である。**
