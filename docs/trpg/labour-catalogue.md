# 労働カタログ

一本道（`one-road-virtue.md`）を歩ける状態にするための、働き口の一覧と変奏の規則。

通し再生の実測で、4200行動のうち**仕事は24回**しかなかった。
優先順位を上げても増えなかったので、順番の問題ではなく**存在しない**問題である。
リストに無い選択肢は昇格できない。ここはその穴を埋めるための設計文書である。

## 三つの約束

### 1. 反復可能であること

同じ働き口へ何度でも行ける。一度きりではない。
道の主人公はDay16からDay39まで、同じ岸で**九日**荷を担いだ。
その九日があるからDay39にセレス船長が断った荷の中身を教えてくれる。
**身分証を持たない者にとって、通った回数が唯一の信用である。**

一度きりの場面（実装済みの初任給三択など）はこの穴を埋めない。

### 2. 反復であって繰り返しではないこと

**同じ働き口でも、二度同じ文章を出さない。**

一回ごとに変わるものを四つ持たせる。

| 変わるもの | 例（港湾の荷役） |
|---|---|
| **何を扱ったか** | 塩樽／魚箱／材木／麻袋／中身を聞かされていない木箱 |
| **誰と組んだか** | 無口な年寄り／口の減らない若手／今日が初日の男／グレン本人 |
| **何が起きたか** | 何も起きない／縄が切れる／数が合わない／雨で中断 |
| **何を聞いたか** | 賃金の愚痴／領主が倒れた／北の要塞の噂／何も聞かない |

四つを掛け合わせれば、同じ荷役でも重複しない。
そして**「何も起きない／何も聞かない」を必ず選択肢に残す。**
毎回何かが起きる仕事は、仕事ではなく事件である。

### 3. 拾えるものが混ざること

変奏のうち一定割合は、**後で意味を持つ。**
Day33に港で見た「中身を知らされていない木箱」は、正本のT14第一取引である。
その日は何も起きず、Day56に思い出される。

ただし**毎回混ぜない。**十回のうち二回か三回でいい。
残りは本当にただの労働で、疲れて、金が入って、腹が減る。

### 4. 働き口の画面も三択であること

働き口の画面が一択になってはいけない。一択は選ばせていないのと同じである。

だが刻限は本物にしたい。朝の荷役は朝しか無いし、夜の荷運びは夜しか無い。
そこで**今すぐ入れる口が三つに満たない時は、まだ開いていない口を
「待って入る」形で並べる。**待ち時間はそのまま作業時間に足す。
賃金も消耗もその働き口のまま変わらない。待つこと自体が選択だからである。

- 3時間先に開くなら「——3時間ほど待って、次の刻の口に入る」
- 今日の分が終わっているなら「——明朝の口に、今から名前を入れておく」

この規則が成り立つために、**表に載る施設はどこも働き口を三つ以上持つ。**
下層の安宿の皿洗い一口だけ、という状態は許さない。

## 賃金の基準

正本の価格表に対して整合させる。田園の村の麦粥1G、素泊まり4G、
王都の雑魚寝3G、交易都市の船員相部屋6Gが物差しになる。

| 区分 | 拘束 | 賃金 | 目安 |
|---|---|---:|---|
| 軽作業 | 1〜2時間 | 1〜2G | 一食ぶん |
| 半日仕事 | 3〜4時間 | 3〜5G | 一泊ぶん |
| 一日仕事 | 6〜8時間 | 6〜8G | 一泊と二食 |
| 都市の荷役 | 3〜4時間 | 5〜8G | 港と市場は割がいい |
| 危険・不快 | 変動 | +2〜3G | 雨天、深夜、汚れ仕事 |

**疲労は賃金に比例する。**8Gの仕事は疲労もそれなりに乗る。
道のDay14で港湾荷役に入った後、疲労は88まで上がっている。

**信用が付くと賃金ではなく待遇が変わる。**
道のDay17で「グレンが一言添えたので割の良い便に入れられた」がそれである。
同じ3時間で8Gになる。額を上げるのではなく、**選ばれる側に回る。**

## 読み書きの扱い

村長宅の清書と税関の書類写しだけ「読み書きが要る」としてある。

**これはスキルではない。**召喚された者は最初から字が読める。
正本のプレイヤー設定は「身分証なし、金なし、土地勘なし」であって、
文盲とは書かれていない。**この世界の側が識字を稀少にしている**だけである。

だから賃金が高い。**同じ半日で、馬房掃除3Gに対し書類写し6G。**
そしてこれは道の主人公にとって、身分証の代わりになる唯一の技能である。

## スキルの扱い

**スキルは戦闘にのみ関与する。会話・調査・労働・トラブル解決には一切関与しない。**

正本のスキルデータの実際の形がそう言っている。

```
target: "single_enemy"
damage: { formula, perHitMultiplier, hits, accuracyModifier }
cooldown: { battleTurns, usesPerBattle }
costs: { mp, hp }
```

対象は敵、効果は倍率と命中、消費はMPとHP、冷却はターン数。
**戦闘の外に出る欄が一つも無い。**

したがって道の側で守る規則。

- **「このスキルが無いとクリア不可」を作らない。**
  T01からT19まで、どのトラブルも、どのスキル構成でも解決に到達できる
- **会話の成否をスキルで判定しない。**
  Day37でニコラスが妹の話をするのは、夕方の裏路地で二時間待った者にだけである。
  説得スキルの数値ではない
- **労働にスキルを要求しない。**
  荷役に筋力値は要らない。**通った回数だけが条件である**
- **戦闘は避けられる。**
  道は四十八日間、武器を一本も買わずにDay48の奪還まで行っている。
  戦闘を選ぶ者にはスキルが効き、選ばない者には別の道がある

**スキル構成で変わるのは、戦う時にどう戦うかだけ。**
戦うかどうか、勝った後に何が残るかは、スキルの外側で決まる。

## 変奏の書き方（実例）

道のDay15〜Day39で「朝の荷役」が六回出る。**六回とも別の場面にする。**

| 日 | 何を | 誰と | 何が | 何を聞いた |
|---|---|---|---|---|
| Day15 | 塩樽 | 無口な年寄り | 何も起きない | 何も聞かない |
| Day16 | 麻袋 | 若手三人 | 荷が半分しか出ない | **領主が倒れた** |
| Day17 | 材木 | グレンの口利きで良い便 | 何も起きない | 割当の不公平 |
| Day31 | 魚箱 | 久しぶりの顔ぶれ | 縄が切れて足を打つ | 割当が貼り出された |
| Day32 | 陶器 | 今日が初日の男 | 一つ割る。弁償なし | 男の身の上話 |
| Day33 | **中身を知らされていない木箱** | 若手だけ | 何も起きない | **何も聞かされない** |

Day33だけが後で効く（T14）。残り五回はただの労働である。
**六分の一。**これくらいの比率で混ぜる。

そして**Day32の「一つ割る。弁償なし」**のような、
損も得もしないが記憶に残る回を必ず入れる。
全部が意味のある回だと、労働が労働に見えなくなる。
